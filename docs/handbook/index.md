# 开始使用

Sca4d-J（Scaffold for Java）是一个通用 Java 后端工程模板，包含 Spring Boot 主应用、可选网关、Vue 管理端以及本地开发所需的 PostgreSQL、Redis、RabbitMQ 和 MinIO 配置。
