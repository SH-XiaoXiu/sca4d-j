# 文档新增、修改与退役规则

## 适用范围

本规则适用于 README 和 `docs/` 中长期维护的页面。

## 新增页面

只有现有页面无法准确回答一个长期问题时才新增页面。新增页面必须：

- 选择一个主要分类和一种文档类型；
- 使用能够说明查询对象或操作任务的标题；
- 加入对应侧边栏，或由侧边栏页面直接链接；
- 说明内容来自哪些代码、配置或现有页面；
- 更新指向旧位置的内部链接。

一次故障处理记录、会议记录、临时实施计划和未完成任务不得成为长期页面。

## 修改页面

接口、配置、状态、操作步骤或规则发生变化时，修改负责完整说明该内容的页面，并搜索所有引用位置。路由、参数、默认值和类型签名必须从当前代码核对。

改写页面前列出原有规则、条件、例外、失败结果、示例和验收要求。改写后逐项确认仍可找到，不得用简短总结替代原文表达的行为。

## 拆分与合并

一个页面混合教程、概念说明、Specification 或 Reference 时，按文档类型拆分。两个页面完整说明同一内容时保留一个主要页面，其他页面改为链接和当前任务所需的说明。

拆分或合并不得删除有效内容。原路径仍有外部使用者时保留可访问入口，并指向新位置。

## 退役页面

删除功能时同步处理代码、配置、运行依赖、测试、导航、正文和参考手册。页面只记录当前版本，不保留已经删除实现的说明。

需要保留旧版本文档时使用独立版本站点或发布记录，不把多个版本的规则写在同一页面。

## 验收要求

- 每个页面只有一种文档类型。
- 每个长期页面都可以从导航或正文入口访问。
- 原有规则、例外、失败结果、示例和验收要求均有明确位置。
- 删除或改名的路径没有失效内部链接。
- VitePress 构建和页面布局检查通过。
