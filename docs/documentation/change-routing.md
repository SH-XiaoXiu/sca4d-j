# 变化与维护位置

## 内容位置

| 变化 | 主要位置 | 同时检查 |
| --- | --- | --- |
| 项目起源和设计思想 | `author-note/` | 项目定位、项目规范、AI 协作 |
| 项目名称、定位、维护团队 | README、`handbook/` | 首页、部署信息 |
| 顶层模块、首次运行方式 | `handbook/` | README、运维、模块目录 |
| 应用组成、分层、身份、权限、数据处理方式 | `architecture/` | 项目规范、开发指南、参考手册 |
| 标准功能开发步骤 | `development/` | 对应内置功能页面 |
| 后端、网关、管理端、数据库和文档规则 | `standards/` | 示例、测试和审查清单 |
| 多个业务模块使用的公共接口和实现 | `infrastructure/` | 系统设计、项目规范、运维、参考手册 |
| 环境、配置、构建和部署 | `operations/` | 项目手册、配置参考 |
| 路由、接口、注解、枚举、错误码 | `reference/` | OpenAPI、使用这些内容的教程 |
| Agent 执行规则、教程和提示词 | `ai-collaboration/` | 首页入口、项目规范链接 |
| 文档分类、编辑和审查规则 | `documentation/` | 更新项目文档教程 |

## 代码变化检查表

| 变化 | 至少检查 |
| --- | --- |
| 新增数据库表 | 数据说明、持久化规则、Flyway 说明、模块目录、相关教程 |
| 新增 HTTP 接口 | 开发步骤、权限、HTTP 参考、OpenAPI、错误码、前端 API |
| 新增配置项 | Properties、`.env.example`、配置参考、部署、启动检查、故障处理 |
| 新增枚举或状态 | 数据库存储、Java 类型、OpenAPI、前端选项、状态参考、状态变化 |
| 新增权限 | 权限目录、Controller 常量、角色初始化、参考手册、管理端、授权测试 |
| 新增数据访问范围 | Action、Criteria、Policy、Repository、SYSTEM 行为、系统设计、测试 |
| 新增消息或事件 | 发布时间、Payload、routing key、消费幂等、日志、故障处理 |
| 新增后台任务 | 多实例竞争、幂等、批次、恢复、配置、指标、运维、项目规范 |
| 新增文件使用场景 | 业务字段、Policy、签名、上传确认、删除清理、前端、教程 |
| 新增管理端页面 | 路由权限、API、加载和错误状态、响应式、键盘操作、测试 |
| 修改构建或部署 | README、项目手册、运维、配置参考、产物、回滚限制 |
| 修改项目规范 | 受影响的代码、示例、测试、审查清单和相关说明 |

不受影响的项目可以标记为“不适用”，并写明判断依据。代码只修改一个模块时，仍需检查公开接口、配置和运行结果。
