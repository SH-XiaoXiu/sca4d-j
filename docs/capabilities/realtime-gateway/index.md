# 实时通信与 Gateway

本目录说明浏览器实时通知（Web Realtime）和独立 Gateway。Web Realtime 只向在线连接推送允许丢失的事件。Gateway 为 API、SSE、WebSocket 和回调提供负载均衡入口。适用读者为开发实时通知、订阅策略和 Gateway 路由的开发者。
